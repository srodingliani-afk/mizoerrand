5. TECHNICAL ARCHITECTURE, STORAGE ADAPTER & API MODULES
------------------------------------------------------------------------
Frontend : React 19 + TypeScript + Vite + Tailwind CSS v4 + Lucide Icons
           + PWA Service Worker + IndexedDB Offline Cache + SSE Stream
           + Browser MediaRecorder API (15s Voice Notes)
Backend  : Node.js + Express (server.ts) + Gzip Compression + Live GPS
           Cache + Realtime SSE Hub
Database : Storage Abstraction Layer (server/infrastructure/dbAdapter.ts)
           * Interface: StorageAdapter<TState>
           * Dev Mode : LocalJsonStorageAdapter (atomic temp-file +
                        fs.renameSync writes to .data/zorun-db.json)
           * Prod Swap: PostgresStorageAdapter (Supabase / PostgreSQL
                        ready via DATABASE_URL or SUPABASE_DB_URL with
                        schema DDL & local write-through safety mirror)
